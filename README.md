TempoLock — Adaptive Countdown Lock Screen Studio

An interactive smartphone lock screen web application built for the Handshake AI × Google Challenge (Your Deadline, Your Design). TempoLock blends real-time countdown tracking, a dual-mode aesthetic switcher (Executive Studio & Cozy Companion), minute-by-minute encouraging micro-messages, and a high-resolution PNG wallpaper exporter—all while keeping top lock screen clock headroom unobstructed.

✨ Key Features

Dual-Mode Aesthetic Architecture:

.Executive Studio: Pairs crisp Swiss typography (Inter & JetBrains Mono) with four kinetic geometric instruments (Obsidian Gyroscope, Sand Hourglass Orb, Sage Pendulum, and Terracotta Horizon Ring) set against grounded editorial palettes (Sage & Warm Sand, Obsidian Slate, Earthy Terracotta, and Midnight Indigo).

.Cozy Companion: Features four gender-neutral multi-part animated spirits (Mochi Cloud, Cosmo Star, Pip Sprout, and Boba Spirit) across 60fps HTML5 Canvas storybook worlds with tap-to-cheer particle bursts.

.Minute-by-Minute Pacing & Encouragement: Automatically updates a frosted lock screen notification banner every minute with context-aware prompts (from steady pacing checkpoints to a final 60-second sprint alert).

.Custom Deadline & Live Simulation Controls: Customize any target date, time, and event label—or test -1 Min ticks and the final-minute preview state on demand.

.1080×2400 PNG & Dual-Showcase Exporter: Export either lock screen mode individually at mobile resolution (1080×2400) with clean clock headroom, or generate a side-by-side presentation sheet (2460×2680) showcasing both modes together.

🚀 Quick Start (Run Locally or Deploy to GitHub Pages)

Because TempoLock is built as a zero-build, single-file web application, no package installation or bundler is required:

Clone the repository:

git clone https://github.com/<asayusingh243-maker>/tempoLock-Dual-Mode-Animated-Countdown-Lock-Screen.git 
cd TempoLock-Dual-Mode-Animated-Countdown-Lock-Screen


Run locally:
Rename countdown-lock-screen.html to index.html (if deploying to GitHub Pages) and open it directly in any modern browser.

Host live with GitHub Pages:
Go to Settings → Pages in your GitHub repository, set the source branch to main (/root), and save to get a live shareable URL.

🛠️ Built With
